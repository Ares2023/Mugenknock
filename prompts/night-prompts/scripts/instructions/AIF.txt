【難易度】
- 入門〜中級レベル：AIと機械学習の基本概念・AWS AI/MLサービスの活用知識
- 実装詳細より「何に使えるか」「どのサービスを選ぶか」を重視
- Amazon Bedrock・SageMaker・責任あるAI を中心的トピックとして扱う
- **重要**: 実際の AIF 試験の約40%はAWSサービス非依存の一般的なAI・ML概念を問う。AWSサービス問題と一般AI問題を適切に混在させること

【問題スタイル】
- 4択（単一正解）を基本とし、または5択から2択の複数正解
- 具体的なビジネスシナリオ・ユースケースから最適なAIサービスを選ぶ形式
- 「最も適切」「最小の変更」「最もコスト効率が高い」などの条件を含める
- プロンプト末尾の【現在のドメイン別問題数】は参考情報。まだカバーが薄いサービス・概念を優先すること

【問題文・選択肢の目安文字数】
- 問題文（questionText）: 80〜250字（ビジネス要件・制約を具体的に記述）
- 選択肢（choices）: 各20〜70字（サービス名とその活用方法を明示）

【避けること】
- 正解の選択肢の文字数が不正解の選択肢群から浮かないようにすること（正解の文字数を不正解の平均文字数に近づけること）
- 廃止・非推奨のサービス
- MLA・SAA レベルの実装詳細を問う問題
- 正解が自明すぎる問題

【公式試験ガイド概要 (AIF-C01)】
■ 公式タスク文（出題で必ずカバーすること）
【第1ドメイン：AIとMLの基礎】
- Task 1.1: 基本的なAIの概念と用語を説明する
- Task 1.2: AIの実際のユースケースを特定する
- Task 1.3: ML開発ライフサイクルを説明する
【第2ドメイン：生成AIの基礎】
- Task 2.1: 生成AIの基本概念を説明する（大規模言語モデル（LLM）・基盤モデル・Transformer・トークン・埋め込み・ハルシネーション・コンテキストウィンドウ）
- Task 2.2: ビジネス課題解決における生成AIの能力と限界を理解する
- Task 2.3: 生成AIアプリケーション構築のためのAWSインフラストラクチャと技術を説明する
【第3ドメイン：基盤モデルのアプリケーション】
- Task 3.1: 基盤モデルベースのアプリケーションの設計上の考慮事項を説明する
- Task 3.2: 効果的なプロンプトエンジニアリング技術を選択する
- Task 3.3: 基盤モデルのトレーニングとファインチューニングプロセスを説明する
- Task 3.4: 基盤モデルのパフォーマンスを評価する方法を説明する
【第4ドメイン：責任あるAIのガイドライン】
- Task 4.1: 責任あるAIシステムの開発を説明する
- Task 4.2: 透明性と説明可能なモデルの重要性を認識する
【第5ドメイン：AIソリューションのセキュリティ、コンプライアンス、ガバナンス】
- Task 5.1: AIシステムをセキュリティ保護する方法を説明する
- Task 5.2: AIシステムのガバナンスとコンプライアンス規制を認識する
