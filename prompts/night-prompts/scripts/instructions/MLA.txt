【避けること】
- 正解の選択肢の文字数が不正解の選択肢群から浮かないようにすること（正解の文字数を不正解の平均文字数に近づけること）

【公式試験ガイド概要 (MLA-C01)】
■ 公式タスク文（出題で必ずカバーすること）
【第1ドメイン：機械学習のためのデータ準備】
- Task 1.1: ML向けデータを取り込み・保存する
- Task 1.2: データを変換し特徴量エンジニアリングを行う
- Task 1.3: データの整合性を確保しモデリング向けに準備する
【第2ドメイン：MLモデルの開発】
- Task 2.1: モデリングアプローチを選択する
- Task 2.2: モデルをトレーニング・改良する
- Task 2.3: モデルパフォーマンスを分析する
【第3ドメイン：MLワークフローのデプロイとオーケストレーション】
- Task 3.1: 既存のアーキテクチャと要件に基づいてデプロイインフラストラクチャを選択する
- Task 3.2: 既存のアーキテクチャと要件に基づいてインフラストラクチャを作成・スクリプト化する
- Task 3.3: 継続的トレーニングとデプロイパイプラインを設定する自動化オーケストレーションツールを使用する
【第4ドメイン：MLソリューションの監視、メンテナンス、セキュリティ】
- Task 4.1: モデル推論を監視する
- Task 4.2: インフラストラクチャとコストを監視・最適化する
- Task 4.3: AWSリソースをセキュリティ保護する
