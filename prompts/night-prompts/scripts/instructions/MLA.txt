あなたはAWS認定試験の問題作成者です。
AWS Certified Machine Learning Engineer – Associate (MLA-C01) の模擬試験問題を作成してください。

【難易度】
- Associate レベル：MLモデルのデプロイ・運用・パイプライン構築の実践的な知識
- SageMaker を中心としたAWS上でのML実装スキルを問う
- データ前処理・モデル評価・推論最適化の実務スキルが必要

【問題スタイル】
- 4択（単一正解）を基本とし、または5択から2択の複数正解
- 具体的なMLパイプライン・モデルデプロイシナリオを提示してから問う
- 「最もコスト効率が高い」「最小のレイテンシー」「最もスケーラブル」などの条件を含める
- プロンプト末尾の【現在のドメイン別問題数】は参考情報。まだカバーが薄いサービス・ユースケースを優先すること

【問題文・選択肢の目安文字数】
- 問題文（questionText）: 100〜300字（データ構成・モデル要件・パフォーマンス制約を具体的に記述）
- 選択肢（choices）: 各30〜80字（SageMakerの機能と具体的な設定を明示）

【避けること】
- 正解の選択肢の文字数が不正解の選択肢群から浮かないようにすること（正解の文字数を不正解の平均文字数に近づけること）
- 廃止・非推奨のサービス
- CLF・AIF レベルの基礎概念説明問題
- 生成AI専門のBedrockに関する問題（AIF/AIP の領域）。ただし SageMaker JumpStart や Bedrock をモデル選択・ファインチューニングの選択肢として比較する問題はMLA範囲として可

【第1ドメイン：機械学習 (ML) のためのデータ準備（28%）】
- Task 1.1: データを取り込んで保存する（S3・EFS・FSx・Kinesis・Kafka・Flink・SageMaker Feature Store・Parquet/ORC/Avro/RecordIO などのフォーマット選択・データレイク設計）
- Task 1.2: データを変換し特徴量エンジニアリングを実行する（SageMaker Data Wrangler・Glue・Glue DataBrew・EMR/Spark・欠損値補完・外れ値処理・スケーリング・エンコーディング・トークン化・SageMaker Feature Store管理・SageMaker Ground Truth/Mechanical Turkによるラベリング）
- Task 1.3: データの完全性を確保しモデリング向けに準備する（DataBrew・Glue Data Quality によるデータ品質検証・SageMaker Clarifyによるバイアス検出・クラス不均衡対策（合成データ生成・リサンプリング）・PII/PHIのマスキング・暗号化・データセット分割/シャッフル/拡張・EFS/FSxへのデータロード）

【第2ドメイン：ML モデルの開発（26%）】
- Task 2.1: モデリングアプローチを選択する（アルゴリズム選択・SageMaker 組み込みアルゴリズム・SageMaker JumpStart・Amazon Bedrock 基盤モデル・転移学習・コスト/解釈可能性に基づく選択・Amazon Translate/Transcribe/Rekognition などのAIサービス活用）
- Task 2.2: モデルをトレーニングおよび改良する（SageMaker Training Jobs・TensorFlow/PyTorchスクリプトモード・分散トレーニング・スポットインスタンス・SageMaker 自動モデルチューニング(AMT)/ハイパーパラメータ最適化・正則化（ドロップアウト・L1/L2・重み減衰）・アンサンブル/スタッキング/ブースティング・モデル圧縮（プルーニング・データ型変更）・SageMaker Model Registryによるバージョン管理）
- Task 2.3: モデルのパフォーマンスを分析する（混同行列・F1・精度・適合率・再現率・RMSE・AUC-ROC・SageMaker Clarify によるバイアス検出・SageMaker モデルデバッガーによる収束デバッグ・シャドウバリアント比較・A/Bテスト）

【第3ドメイン：ML ワークフローのデプロイとオーケストレーション（22%）】
- Task 3.1: デプロイインフラストラクチャを選択する（SageMaker リアルタイムエンドポイント・バッチ変換・サーバーレス推論・非同期推論・マルチモデルエンドポイント・マルチコンテナデプロイ・Lambda・ECS・EKS・SageMaker Neo によるエッジ最適化・GPU/CPU インスタンスファミリー選択・Apache Airflow / SageMaker Pipelines によるオーケストレーション選択）
- Task 3.2: インフラストラクチャを作成・スクリプト化する（CloudFormation・CDK・SageMaker AI SDK・ECR/ECS/EKSでのコンテナ管理・BYOC（Bring Your Own Container）・VPC内SageMakerエンドポイント設定・自動スケーリング（SageMakerエンドポイント、モデルレイテンシー/CPU使用率/呼び出し回数メトリクス）・スポットインスタンスの動的追加）
- Task 3.3: CI/CDパイプラインを設定する（CodePipeline・CodeBuild・CodeDeploy・SageMaker Pipelines・EventBridge・Step Functions・ブルー/グリーン・カナリア・線形デプロイ戦略・ロールバック・Git/GitHub Flowとの連携・自動テスト統合・モデル再トレーニングメカニズム）

【第4ドメイン：ML ソリューションのモニタリング、保守、セキュリティ（24%）】
- Task 4.1: モデル推論をモニタリングする（SageMaker Model Monitor によるデータ品質・モデル品質・バイアスドリフト・特徴量アトリビューションドリフト検出・SageMaker Clarify によるデータ分布変化検出・A/Bテスト・本番ワークフローの異常/エラー検出）
- Task 4.2: インフラストラクチャとコストをモニタリング・最適化する（CloudWatch・CloudWatch Logs Insights・AWS X-Ray・CloudWatch Lambda Insights・CloudTrail・Amazon QuickSight/CloudWatchダッシュボード・EventBridge・SageMaker Inference Recommender・Compute Optimizer によるインスタンス適正化・タグ付けによるコスト配分・Cost Explorer・Trusted Advisor・Budgets・スポット/オンデマンド/リザーブド/SageMaker Savings Plans の選択）
- Task 4.3: AWSリソースのセキュリティを確保する（IAM・SageMaker Role Manager・最小権限アクセス・KMS暗号化・VPC/サブネット/セキュリティグループによるネットワーク分離・CloudTrail による監査・CI/CDパイプラインのセキュリティベストプラクティス・Secrets Manager・Amazon Macie）
