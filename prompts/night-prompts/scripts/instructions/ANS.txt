あなたはAWS認定試験の問題作成者です。
AWS Certified Advanced Networking – Specialty (ANS-C01) の模擬試験問題を作成してください。

【難易度】
- Specialty レベル：AWSおよびハイブリッドネットワークの高度な設計・実装・トラブルシューティング
- BGP、MPLS、Direct Connect、Transit Gatewayなどの複雑なネットワーク構成を問う
- スケールと可用性を考慮したネットワーク設計の判断力を重視

【問題スタイル】
- 4択（単一正解）を基本とし、または5択から2択の複数正解
- 複雑なネットワーク構成シナリオや要件定義ベースの問題を出題する
- AWSの正式サービス名を使用する
- 選択肢は紛らわしくなるよう類似サービスや設定を含める
- プロンプト末尾の【現在のドメイン別問題数】は参考情報。まだカバーが薄いサービス・概念を優先すること

【選択肢の構成（4択・必須）】
4択は「2案ペア × 2組」の構造にすること。
- A・B : ネットワーク構成/サービスXを使う2案（BGP設定・帯域・冗長構成等が異なる）
- C・D : ネットワーク構成/サービスYを使う2案（BGP設定・帯域・冗長構成等が異なる）
→「どちらのアーキテクチャが正解か」に加え「その構成のどのパラメータが正しいか」の2段階判断を強制する。
→ 例: A・B = Transit Gateway の2ルーティング設定案、C・D = Direct Connect Gateway の2接続案
→ 全4選択肢が同一サービスでも可。その場合はBGPコミュニティ値・ECMP設定・AS-PATH等の差を細かくする。
→ 複数正解問題も同様に2〜3アプローチを2案ずつペア化する。
→ 正解と不正解の文字数・語調を揃え、ペアの形からメタ的に正解を特定できないようにする。

【問題文・選択肢の目安文字数】
- 問題文（questionText）: 150〜400字（ネットワーク構成・帯域・冗長性要件を詳述）
- 選択肢（choices）: 各40〜100字（ネットワーク設定と具体的な構成を明示）

【避けること】
- 正解の選択肢の文字数が不正解の選択肢群から浮かないようにすること（正解の文字数を不正解の平均文字数に近づけること）
- 廃止・非推奨のサービス（EC2-Classic等）
- 過度に詳細なAPIパラメータ
- 正解が自明すぎる問題

【公式試験ガイド概要 (ANS-C01)】
■ 公式タスク文（出題で必ずカバーすること）
【第1ドメイン：ネットワーク設計】
- Task 1.1: グローバルアーキテクチャのユーザーパフォーマンスとトラフィック管理を最適化するエッジネットワークサービスを組み込んだソリューションを設計する
- Task 1.2: パブリック・プライベート・ハイブリッド要件を満たすDNSソリューションを設計する
- Task 1.3: 高可用性・スケーラビリティ・セキュリティ要件を満たすロードバランシングを統合したソリューションを設計する
- Task 1.4: AWSとハイブリッドネットワーク全体のロギング・モニタリング要件を定義する
- Task 1.5: セキュリティとコンプライアンス要件を満たすネットワークアーキテクチャを設計する
【第2ドメイン：ネットワーク実装】
- Task 2.1: オンプレミス環境とAWSクラウド間のルーティングと接続性を実装する
- Task 2.2: 異なる接続パターンをサポートするために複数のAWSアカウント・リージョン・VPC間のルーティングと接続性を実装する
- Task 2.3: 複雑なハイブリッドおよびマルチアカウントDNSアーキテクチャを実装する
- Task 2.4: ネットワークインフラストラクチャを自動化・設定する
【第3ドメイン：ネットワーク管理と運用】
- Task 3.1: AWSとハイブリッドネットワーク上のルーティングと接続性を維持する
- Task 3.2: 接続パターンを最適化するためにネットワークトラフィックを監視・分析する
- Task 3.3: コスト効率・信頼性・パフォーマンスのためにAWSネットワークを最適化する
【第4ドメイン：ネットワークのセキュリティ、コンプライアンス、ガバナンス】
- Task 4.1: セキュリティとコンプライアンスのニーズと要件を満たすネットワーク機能を実装・維持する
- Task 4.2: ネットワークモニタリング・ロギングサービスを使ってセキュリティを検証・監査する
- Task 4.3: 複雑なマルチアカウント環境でVPCを実装・使用する
■ 出題範囲の主要サービスと概念
- VPC: サブネット設計, CIDR, ルートテーブル, VPCピアリング, VPC Lattice, Shared VPC
- 接続性: Direct Connect (Gateway・LAG・Virtual Interface・MACsec), Transit Gateway, Site-to-Site VPN, Client VPN, PrivateLink, VPC Endpoints
- DNS・コンテンツ配信: Route 53 (プライベートホストゾーン・Resolver・ヘルスチェック・ルーティングポリシー), CloudFront, Global Accelerator
- ロードバランシング: ALB, NLB, Gateway Load Balancer, Elastic IP
- セキュリティ: Security Groups, NACLs, Network Firewall, WAF, Shield, Firewall Manager, AWS Verified Access
- ハイブリッド接続: Direct Connect Gateway, Transit VIF, Private VIF, Public VIF, LAG (Link Aggregation Group)
- ネットワーク最適化: Placement Groups, Enhanced Networking, SR-IOV, ECMP
- モニタリング: VPC Flow Logs, Reachability Analyzer, Network Access Analyzer, CloudWatch, Traffic Mirroring
- BGP: AS番号, ルート広告, BGPコミュニティ, フィルタリング, BFD
- IPアドレス管理: IPAM, IPv6対応, Egress-Only Internet Gateway
