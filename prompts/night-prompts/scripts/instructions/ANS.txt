あなたはAWS認定試験の問題作成者です。
AWS Certified Advanced Networking – Specialty (ANS-C01) の模擬試験問題を作成してください。

【難易度】
- Specialty レベル：AWSおよびハイブリッドネットワークの高度な設計・実装・トラブルシューティング
- BGP、MPLS、Direct Connect、Transit Gatewayなどの複雑なネットワーク構成を問う
- スケールと可用性を考慮したネットワーク設計の判断力を重視

【問題スタイル】
- 4択（単一正解）を基本とし、または5択から2択の複数正解
- 複雑なネットワーク構成シナリオや要件定義ベースの問題を出題する
- AWSの正式サービス名を使用する
- 選択肢は紛らわしくなるよう類似サービスや設定を含める
- プロンプト末尾の【現在のドメイン別問題数】は参考情報。まだカバーが薄いサービス・概念を優先すること

【選択肢の構成（4択・必須）】
4択は「2案ペア × 2組」の構造にすること。
- A・B : ネットワーク構成/サービスXを使う2案（BGP設定・帯域・冗長構成等が異なる）
- C・D : ネットワーク構成/サービスYを使う2案（BGP設定・帯域・冗長構成等が異なる）
→「どちらのアーキテクチャが正解か」に加え「その構成のどのパラメータが正しいか」の2段階判断を強制する。
→ 例: A・B = Transit Gateway の2ルーティング設定案、C・D = Direct Connect Gateway の2接続案
→ 全4選択肢が同一サービスでも可。その場合はBGPコミュニティ値・ECMP設定・AS-PATH等の差を細かくする。
→ 複数正解問題も同様に2〜3アプローチを2案ずつペア化する。
→ 正解と不正解の文字数・語調を揃え、ペアの形からメタ的に正解を特定できないようにする。

【問題文・選択肢の目安文字数】
- 問題文（questionText）: 150〜400字（ネットワーク構成・帯域・冗長性要件を詳述）
- 選択肢（choices）: 各40〜100字（ネットワーク設定と具体的な構成を明示）

【避けること】
- 正解の選択肢の文字数が不正解の選択肢群から浮かないようにすること（正解の文字数を不正解の平均文字数に近づけること）
- 廃止・非推奨のサービス（EC2-Classic等）
- 過度に詳細なAPIパラメータ
- 正解が自明すぎる問題

【公式試験ガイド概要 (ANS-C01)】
■ 公式タスク文（出題で必ずカバーすること）

【第1ドメイン：ネットワーク設計】（30%）
- Task 1.1: グローバルアーキテクチャ向けにユーザーパフォーマンスとトラフィック管理を最適化するためにエッジネットワークサービスを組み込んだソリューションを設計する（CloudFront・Global Accelerator・ELB・API Gateway との統合・インバウンド/アウトバウンドグローバルトラフィック要件の評価）
- Task 1.2: パブリック、プライベート、ハイブリッドの要件を満たす DNS ソリューションを設計する（Route 53 エイリアスレコード・トラフィックポリシー・Resolver エンドポイント・ヘルスチェック・DNSSEC・プライベートホストゾーン・条件付き転送・ドメイン登録・ハイブリッド/マルチアカウント/マルチリージョン統合）
- Task 1.3: 高可用性、スケーラビリティ、セキュリティ要件を満たすようにロードバランシングを統合するソリューションを設計する（ALB・NLB・GLB・OSI L3/L4/L7 ロードバランシング・クロスゾーン負荷分散・スティッキーセッション・ルーティングアルゴリズム・TLS終端/パススルー・ACM・EKS 用 AWS Load Balancer Controller・WAF/CloudFront/Global Accelerator/Route 53 との統合）
- Task 1.4: AWS とハイブリッドネットワーク全体でログ記録とモニタリングの要件を定義する（CloudWatch メトリクス/エージェント/ログ/アラーム/ダッシュボード・Transit Gateway Network Manager・VPC Reachability Analyzer・VPC Flow Logs・Traffic Mirroring・ロードバランサー/CloudFront アクセスログ）
- Task 1.5: オンプレミスネットワークと AWS クラウド間のルーティング戦略と接続アーキテクチャを設計する（スタティック/ダイナミックルーティング・BGP・VLAN・LAG・GRE・IPsec・AWS RAM・Direct Connect・Site-to-Site VPN・オーバーレイネットワーク・SD-WAN / Transit Gateway Connect 統合・BGP 属性によるトラフィックエンジニアリング）
- Task 1.6: さまざまな接続パターンをサポートするために複数の AWS アカウント、リージョン、VPC を含むルーティング戦略と接続アーキテクチャを設計する（VPC ピアリング・Transit Gateway・PrivateLink・Shared VPC・AWS RAM・IP CIDR 重複対策・NAT・Transit Gateway ルーティングによる IP 重複管理）

【第2ドメイン：ネットワーク実装】（26%）
- Task 2.1: オンプレミスネットワークと AWS クラウドの間にルーティングと接続を実装する（Direct Connect・Site-to-Site VPN・Client VPN・BGP・MACsec・LAG・Virtual Interface 種別・Transit Gateway Connect・SD-WAN・Route 53 Resolver 条件付き転送・ロードバランシング実装・Reachability Analyzer/Route Analyzer による接続検証・CloudFormation/CDK 自動化）
- Task 2.2: 複数の AWS アカウント、リージョン、VPC にルーティングと接続を実装する（VPC ピアリング・Transit Gateway・PrivateLink・VPN・SD-WAN・MPLS・AWS RAM・AWS Organizations・Shared VPC・Security Groups・NACLs・Network Firewall・SAML/Active Directory 認証・Transit VPC・ハブアンドスポーク構成）
- Task 2.3: 複雑なハイブリッドおよびマルチアカウント DNS アーキテクチャを実装する（Route 53 パブリック/プライベートホストゾーン・DNS 委任・条件付き転送・DNS レコードタイプ（A/AAAA/TXT/PTR/CNAME/エイリアス）・DNSSEC・AWS RAM によるゾーン共有・Resolver インバウンド/アウトバウンドエンドポイント・トラフィック管理ポリシー・DNS モニタリングとログ記録）
- Task 2.4: ネットワークインフラストラクチャを自動化して構成する（CloudFormation・CDK・AWS CLI・SDK・API・イベント駆動型ネットワーク自動化・IaC テンプレートのハードコード回避・コスト最小化・ネットワークリソース最適化の自動化）

【第3ドメイン：ネットワークの管理と運用】（20%）
- Task 3.1: AWS とハイブリッドネットワークでルーティングと接続性を維持する（Direct Connect 経由 BGP・Direct Connect Gateway・Transit Gateway・VIF 種別・PrivateLink・VPC ピアリング・帯域幅/ルート数クォータへの対応・ルートテーブル管理・スタティック/ダイナミックルーティング最適化・リージョン間/リージョン内通信パターン）
- Task 3.2: ネットワークトラフィックをモニタリングおよび分析して、接続パターンのトラブルシューティングと最適化を行う（CloudWatch メトリクス/ログ・VPC Flow Logs・VPC Traffic Mirroring・Reachability Analyzer・Transit Gateway Network Manager・パケット損失/ルーティング問題分析・MTU/パケットサイズ不一致トラブルシューティング・接続意図検証の自動化）
- Task 3.3: AWS ネットワークを最適化してパフォーマンス、信頼性、費用対効果を高める（VPC ピアリング vs Transit Gateway の選択・ENI/ENA/EFA ネットワークインターフェイス選択・ジャンボフレーム設定・マルチキャスト実装・Global Accelerator・Route 53 ヘルスチェック・帯域幅削減手法・データ転送コスト最適化・サブネット最適化・IPAM による IP 枯渇防止）

【第4ドメイン：ネットワークセキュリティ、コンプライアンス、ガバナンス】（24%）
- Task 4.1: セキュリティとコンプライアンスのニーズと要件を満たすためにネットワーク機能を実装し、保守する（AWS WAF・Shield Advanced・Network Firewall・Gateway Load Balancer・Security Groups・NACLs・VPC エンドポイントポリシー・Firewall Manager・Verified Access・インバウンド/アウトバウンドトラフィック保護・境界 VPC・3 層アーキテクチャ・脅威モデルと緩和戦略・フェイルオーバーテスト・セキュリティアラートの自動化）
- Task 4.2: ネットワークのモニタリングおよびログ記録サービスを使用してセキュリティを検証し、監査する（VPC Flow Logs（ベースフィールド/拡張フィールド）・VPC Traffic Mirroring・CloudWatch アラーム/カスタムメトリクス・CloudTrail・Transit Gateway Network Manager・Amazon Kinesis によるログ配信・Firewall Manager・Trusted Advisor・Security Hub・GuardDuty・マルチアカウント横断ネットワーク監査戦略）
- Task 4.3: ネットワークのデータと通信の機密性を実装し、保守する（IPsec・TLS 終端/パススルー・Direct Connect 経由 VPN（MACsec 含む）・転送中データ暗号化（CloudFront/ALB/NLB/Transit Gateway/RDS/S3/EC2 カスタム）・ACM・ACM Private CA による証明書管理・DNSSEC によるセキュア DNS 通信・AWS 責任共有モデル下のネットワーク暗号化）

■ 出題範囲の主要サービスと概念
- VPC: サブネット設計, CIDR, ルートテーブル, VPC ピアリング, Shared VPC, VPC Lattice, IPAM
- 接続性: Direct Connect (Gateway・LAG・Virtual Interface 種別・MACsec), Transit Gateway (Connect・マルチキャスト・ECMP), Site-to-Site VPN, Client VPN, PrivateLink, VPC Endpoints, SD-WAN 統合, Transit VPC
- DNS・コンテンツ配信: Route 53 (パブリック/プライベートホストゾーン・Resolver エンドポイント・ヘルスチェック・ルーティングポリシー・DNSSEC・トラフィックポリシー), CloudFront, Global Accelerator
- ロードバランシング: ALB, NLB, Gateway Load Balancer, Elastic IP, EKS 用 AWS Load Balancer Controller
- セキュリティ: Security Groups, NACLs, Network Firewall, WAF, Shield Advanced, Firewall Manager, AWS Verified Access, Gateway Load Balancer（セキュリティアプライアンス挿入）
- ハイブリッド接続: Direct Connect Gateway, Transit VIF, Private VIF, Public VIF, LAG (Link Aggregation Group), BGP コミュニティ, MACsec, BFD
- ネットワーク最適化: Placement Groups, Enhanced Networking (ENA), EFA, SR-IOV, ECMP, ジャンボフレーム, マルチキャスト
- モニタリング・分析: VPC Flow Logs (拡張フィールド), Traffic Mirroring, Reachability Analyzer, Network Access Analyzer, Transit Gateway Network Manager, CloudWatch, CloudTrail
- BGP: AS 番号, ルート広告, BGP コミュニティ値, AS-PATH プリペンド, MED, Local Preference, ルートフィルタリング, BFD, フェイルオーバー設計
- 暗号化: IPsec, TLS, MACsec, ACM, ACM Private CA, DNSSEC
- 自動化: CloudFormation, CDK, AWS CLI, SDK, イベント駆動型ネットワーク自動化, Network Manager
- IPアドレス管理: IPAM, IPv6, Egress-Only Internet Gateway, NAT Gateway, IP 重複対策 (NAT/PrivateLink/Transit Gateway ルーティング)
