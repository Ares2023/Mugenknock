# 通報ブロックリスト（悪意ある・迷惑通報者の userId を列挙）
#
# ここに列挙した userId(Cognito sub) からの通報は、夜間の 03-check-reports.sh が
# Claude に一切渡さず、Reports テーブルから即削除します。
# → その通報は問題・UI・仕組みに一切影響しません（入口で遮断）。
#
# 使い方:
#   1) 管理画面の通報一覧 (/admin/reports) で、迷惑通報の userId を確認
#   2) 下に「1行1件」で userId を追記（保存するだけ。デプロイ不要）
#   3) 次回の夜間実行から反映される
#
# 記法: '#' で始まる行と空行は無視。1行1 userId。
# 例:
#   0734fa28-xxxx-xxxx-xxxx-xxxxxxxxxxxx
#
# ※ 'anonymous'（未ログイン通報）をまとめてブロックしたい場合は下行のコメントを外す:
# anonymous
