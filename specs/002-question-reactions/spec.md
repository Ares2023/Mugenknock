# 問題ごとの👍👎リアクション ＆ 演習画面フッターの整理

- 状態: 完了（2026-09-15）
- 起票日: 2026-09-15

## なぜやるか

演習画面の解説の下にボタンが散在していて「うるさい」状態になっている。
コピーボタンは問題文の右上と解説の右上に離れて置かれ、通報・途中採点は
右寄せの別ブロック、さらに「質問プロンプト生成」が加わって整理されていない。

また、問題の良し悪しを利用者から集める手段が通報（＝不備の申告）しかなく、
「間違いではないが分かりにくい／良問だった」といった品質のシグナルが取れない。

## 誰のためか

- [ ] ゲスト（未ログイン）
- [x] ログインユーザー（リアクションを押す）
- [x] 管理者（集計を見て問題改善に使う）
- [ ] 開発者・運用（自分）

> 👍👎は**ログイン専用**。問題IDごとに累積する評価データであり、
> `CLAUDE.md` のゲスト/ログイン境界（累積データはサーバ側で管理）に従う。

## 何を作るか

### 1. 「質問プロンプト生成」機能の廃止
`PromptMenu`（ChatGPT等へ貼るプロンプト生成）をUIごと削除する。機能自体を廃止する。

### 2. 解説下のボタン列を1行に集約（左揃え）
解説の下に、左揃えで以下の順に並べる。

```
[コピー] [♡] [👍] [👎] [⋮]
```

- **コピー** … 問題文＋選択肢＋解答解説をコピー（現在の解説右上のコピー）
- **♡** … ブックマーク。**「問題N」見出し右の☆は廃止し、ここへ移動する**（機能は同じ）
- **👍 / 👎** … 後述のリアクション。押すと選択状態になり、もう一度押すと取り消し
- **⋮** … メニューを開き「この問題を通報」「ここまでで採点」を出す
  （通報・途中採点のボタンは列から消し、このメニューへ格納する）

### 3. コピーボタンの位置
- 問題文＋選択肢のコピー … **選択肢の下に左揃え**（現在は問題文の右上）
- 問題文＋選択肢＋解答解説のコピー … **解説の下に左揃え**（上記ボタン列の先頭）

### 4. 通報・途中採点の文字濃度
`⋮` メニュー内に移すため単体ボタンは無くなるが、演習画面に残る同系統の
補助テキストは ID 表示（`ID: mla-077c52f8` の値部分＝`var(--color-text-sub)`）と
同じ濃度に揃える。

### 5. 👍👎リアクションの記録
- ログインユーザーのみ操作可能。ゲストには押せない状態で見せる（または非表示）。
- **1ユーザー・1問につき1票**。👍→👎の変更、同じものを再押下で取り消しができる。
- ユーザーには**自分が押した状態のみ**表示する。**他ユーザーを含む合計数は見せない**。
- 集計（👍数・👎数）は**管理画面の問題管理から確認できる**ようにし、
  問題改善の指標として使う。

## 対象外（やらないこと）

- ユーザー画面への集計数の表示（受験者正答率のような他者の数字は出さない）
- リアクションを出題ロジック（重み付け・フィルタ）に反映すること
- ゲストのリアクション対応
- 👍👎以外のリアクション種別の追加
