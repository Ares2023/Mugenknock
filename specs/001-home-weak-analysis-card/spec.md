# ホーム画面「苦手分析」カード

- 状態: 完了（2026-09-15）
- 起票日: 2026-09-15

## なぜやるか

Web版（デスクトップ）のホーム画面は、目標演習量・ドメイン別正答率+予想スコア・
日めくりAWSサービスの3カードだけで、その下は演習開始ボタン（画面下固定）まで
ほぼ空白になっている。一方でマイページ「苦手分析」タブには頻出ミス問題・苦手
ドメインの情報があるが、ホームからは見えず、わざわざマイページに移動しないと
気づけない。

## 誰のためか

- [ ] ゲスト（未ログイン）
- [x] ログインユーザー
- [ ] 管理者
- [ ] 開発者・運用（自分）

> 苦手分析・頻出ミス問題は `CLAUDE.md` のゲスト/ログイン境界で明示的に
> **ログイン専用**と定義されている機能。ゲストへの新規開放は行わない。

## 何を作るか

Web版ホーム画面（デスクトップ、`!isMobile`）の右カラム（日めくりAWSサービスの下）に、
「苦手分析」カードを新設する。

- **ログインユーザーかつ `focusedUnlocked`（30問以上回答済み）**:
  マイページ苦手分析タブの「頻出ミス問題」上位2〜3件（問題文の冒頭・誤答回数）と、
  「苦手ドメイン」上位1〜2件（正答率が閾値未満のドメイン名）を要約表示する。
  各項目・カード自体のクリックでマイページの該当タブへ遷移する（新規モーダルは作らない）。
- **ログインユーザーだが `focusedUnlocked` 未達**（30問未満）:
  「あとX問でアンロック」の案内のみ（既存のFocusedモードの文言と揃える）。
- **ゲスト**:
  カードごと非表示にする（`{user && ...}` で早期リターン）。簡易バナー等の代替UIは
  出さない（ホームには既にログイン導線がヘッダーにあるため、新規に増やさない）。
- モバイル（`isMobile`）には追加しない。今回はWeb版限定の対応。

## 受入条件

- [ ] デスクトップでログイン済み・30問以上回答済みユーザーには、頻出ミス問題と
      苦手ドメインの要約がホーム右カラムに表示される
- [ ] デスクトップでログイン済み・30問未満のユーザーには「あとX問でアンロック」
      の案内のみ表示され、頻出ミス問題・苦手ドメインのAPIは呼ばれない
      （`focusedUnlocked` が false の間は fetch しない）
- [ ] デスクトップでゲストにはカード自体が表示されない
- [ ] モバイルは今回のカード追加による見た目の変化が一切ない
- [ ] カードクリックでマイページの苦手分析タブに遷移する
- [ ] 新しいAPIエンドポイントは追加しない（既存の `/users/me/weak-questions` と
      `/users/me/stats` を再利用する）

## 対象外（やらないこと）

- モバイル版への同カード追加
- ゲストへの機能開放・代替コンテンツ
- 頻出ミス問題の問題詳細をホーム上で展開表示すること（クリックしたらマイページへ遷移するのみ）
- 新しいAPI・DynamoDB属性の追加

## 影響範囲

| 画面 | `src/views/Home.tsx`（右カラムにカード追加、`!isMobile` 限定） |

| DynamoDB | なし |

## 既存の不変条件との整合

- 出題プールの条件 `!isHidden && !!validityCheckedAt` を維持するか: 該当なし（出題ロジックに触れない）
- ドメイン均等化（deficit round-robin）の方針に反しないか: 該当なし
- ゲスト/ログイン境界に反しないか: 反しない。ゲストには非表示にするのみで、
  ローカルに新規の累積データを持たせない
- `correctAnswerIndices` を正準とする不変条件に触れるか: 触れない
